# 🧮 Calculadora Básica en Python

## ¿Qué es este proyecto?

Este es un proyecto simple de Python que crea una **calculadora interactiva**. 

El programa te permite hacer operaciones matemáticas básicas (sumar, restar, multiplicar, dividir) usando la terminal.

---

## 📋 Funcionalidades

La calculadora puede hacer estas 4 operaciones:

- **1. Sumar** → suma dos números
- **2. Restar** → resta dos números
- **3. Multiplicar** → multiplica dos números
- **4. Dividir** → divide dos números (con protección contra división por cero)
- **5. Salir** → cierra el programa

---

## 🚀 Cómo usar el programa

### 1. Abre la terminal
Navega a la carpeta donde esté el archivo `calculator.py`

### 2. Ejecuta el programa
```bash
python calculator.py
```

### 3. Sigue las instrucciones
- Verás un **menú** con las 5 opciones
- Escribe el **número de la operación** (1, 2, 3, 4 o 5)
- Introduce el **primer número**
- Introduce el **segundo número**
- ¡Recibirás el **resultado**!

### 4. Ejemplo de uso
```
===== CALCULADORA =====
1. Sumar
2. Restar
3. Multiplicar
4. Dividir
5. Salir
=======================
Elige una opción (1-5): 1
Introduce el primer número: 150
Introduce el segundo número: 50
Resultado: 200.0

===== CALCULADORA =====
...
```

## 📝 Estructura del código

### Funciones principales

```python
add(a, b)           # Suma dos números
substract(a, b)     # Resta dos números
multiply(a, b)      # Multiplica dos números
divide(a, b)        # Divide dos números
main()              # Menú principal e interacción con el usuario
```

### Partes del programa

1. **Funciones** → Las 4 operaciones matemáticas
2. **Tests** → Comprobaciones para asegurar que el código funciona bien
3. **Main** → El menú interactivo
